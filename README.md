BunchOfEmotes, Base emotes for Inline Skating, Inline Idle, Inline Boosting + Running!

---

Had to give one of my favorite movestyles some luv! Introducing **BRCInlineAnims** plugin.  

This plugin enables you to use any basegame, softBounce or BunchOfEmotes animation you have as:

* —✰ **Idle Inline Animations!**
* —✰ **Skate (Run) Inline Animations!**
* —✰ **Boosting on ground Inline Animations!**
* —✰ **On Foot Run Animation!** *BONUS!*

—✰ **BunchOfEmotes, base game animations and the "softBounceX" animations compatible!**

In other words, I tried to address the stuff NewTrix is currently lacking! And yes its totally compatible with NewTrix too!

### INSTRUCTIONS
Drop the folder with the plugin `.dll` into the location:  

`BepInEx\plugins\BRCInlineAnims\`  

![Installation Directory](https://archive.org/download/igaj3wig/igaj3wig.png)

Start the game once, and restart. Thats it! It uses the same "configuration style" as NewTrix.  
Reference your desired animations in the slots.

**TIP:** If you want to use the default inline skating or default run, just use the default values `"run"` for them, OR toggle the use vanilla options on them! For the default idle just use `"idle"`.

Adjust the YOffset if needed (usually anything from the default value or anything from `0.077-0.13` on most characters looks fire), if your character is a model from community that has skates included (like Niko's Coin with Skates), just set it to `0`.

Uhh dont reccomend altering the Delay values unless you want to.

### KNOWN BUG
Using Millenium Winterland mod gets the idle animations on inline broken, so just beware! (probably because of the snow walk draw effect)
